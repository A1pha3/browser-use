## ChatBrowserUse（推荐）

[示例代码](https://github.com/browser-use/browser-use/blob/main/examples/models/browser_use_llm.py)

`ChatBrowserUse()` 是我们专门为浏览器自动化优化的自研模型，在保持高准确性的同时，完成任务的速度比其他模型快 **3-5 倍**。

```python
from browser_use import Agent, ChatBrowserUse

# 初始化模型（默认使用 bu-latest）
llm = ChatBrowserUse()

# 或者使用高级模型
llm = ChatBrowserUse(model='bu-2-0')

# 创建代理
agent = Agent(
    task="你的任务",
    llm=llm
)
```

### 为什么推荐 ChatBrowserUse？

<AccordionGroup>
  <Accordion title="专为浏览器自动化优化">
    - 针对浏览器交互场景训练，理解页面结构、点击目标、输入字段
    - 对话历史优化，减少重复理解的开销
    - 针对常见网页模式有更好的识别能力
  </Accordion>
  <Accordion title="速度优势">
    - 平均任务完成时间比其他模型快 3-5 倍
    - 更少的 token 消耗
    - 更快的响应时间
  </Accordion>
  <Accordion title="准确性保证">
    - 在浏览器自动化基准测试中表现最佳
    - 更好的页面状态理解
    - 更少的错误重试
  </Accordion>
</AccordionGroup>

### 使用 Responses API（GPT-5.1 Codex 模型）

<Info>
Azure OpenAI 某些模型（如 `gpt-5.1-codex-mini`）需要 `api_version >= 2025-03-01-preview`，这些模型仅支持 [Responses API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/how-to/responses) 而非 Chat Completions API。
</Info>

Browser Use 会自动检测并为这些模型使用 Responses API：

```python
from browser_use import Agent, ChatAzureOpenAI

# 自动检测（推荐）- 为 gpt-5.1-codex-mini 使用 Responses API
llm = ChatAzureOpenAI(
    model="gpt-5.1-codex-mini",
    api_version="2025-03-01-preview",
)

# 或显式启用/禁用任意模型的 Responses API
llm = ChatAzureOpenAI(
    model="gpt-4o",
    api_version="2025-03-01-preview",
    use_responses_api=True,  # 强制使用 Responses API
)

agent = Agent(
    task="你的任务",
    llm=llm
)
```

`use_responses_api` 参数说明：

- `'auto'`（默认）：自动为需要它的模型使用 Responses API
- `True`：强制使用 Responses API
- `False`：强制使用 Chat Completions API

## Ollama（本地模型）

Ollama 允许你在本地运行大语言模型，完全保护隐私。

### 安装步骤

1. 安装 Ollama：[https://github.com/ollama/ollama](https://github.com/ollama/ollama)
2. 启动服务器：`ollama serve`
3. 在新终端中安装模型：`ollama pull llama3.1:8b`

```python
from browser_use import Agent, ChatOllama

llm = ChatOllama(model="llama3.1:8b")
```

### 推荐模型

| 模型 | 大小 | VRAM | 特点 |
|-----|------|------|------|
| llama3.1:8b | ~4.9 GB | ~6 GB | 性价比高，适合大多数任务 |
| llama3.1:70b | ~39 GB | ~48 GB | 能力更强，需要更多资源 |
| qwen2.5:7b | ~4.5 GB | ~6 GB | 中文支持好 |
| deepseek-r1:14b | ~14 GB | ~18 GB | 推理能力强 |

### Ollama 适用场景

**适合使用 Ollama 的情况**：
- 数据隐私敏感，不能将数据发送到外部 API
- 需要大量调用模型，成本考虑
- 网络不稳定，需要离线运行
- 开发测试阶段，快速迭代

**不适合使用 Ollama 的情况**：
- 需要最高准确性
- 网络稳定，成本不是问题
- 需要使用不支持本地运行的模型

## 实践练习

### 练习 1：模型对比测试（⭐⭐）

创建测试脚本，对比不同模型的执行效果：

```python
import asyncio
from browser_use import Agent
from browser_use.models import ChatBrowserUse, ChatOpenAI, ChatGoogle

async def compare_models(task):
    models = {
        "ChatBrowserUse": ChatBrowserUse(),
        "OpenAI GPT-4o": ChatOpenAI(model="gpt-4o"),
        "Google Gemini": ChatGoogle(model="gemini-flash-latest"),
    }

    results = {}
    for name, llm in models.items():
        agent = Agent(task=task, llm=llm)
        history = await agent.run()
        results[name] = {
            "steps": history.number_of_steps(),
            "success": history.is_done(),
        }
        print(f"{name}: {results[name]}")

    return results

# 运行对比
asyncio.run(compare_models("访问 example.com，提取标题"))
```

### 练习 2：选择最适合的模型（⭐⭐⭐）

根据以下场景，选择最合适的模型：

| 场景 | 推荐模型 | 说明 |
|-----|---------|------|
| 快速原型开发 | Gemini Flash | 速度快，成本低 |
| 高准确性需求（银行系统） | Claude 3.5 / o3 | 企业级可靠性 |
| 隐私敏感数据处理 | Ollama（本地） | 数据不出本地 |
| 大规模批量任务 | ChatBrowserUse | 性价比高 |
| 需要长上下文理解 | Claude 3.5 | 100K+ context window |

### 练习 3：成本优化策略（⭐⭐⭐）

**心智模型：成本-质量权衡**

```
低成本 → 高成本
  ↓
Ollama → Gemini → ChatBrowserUse → Claude/GPT-4o
  ↓                              ↓
简单任务                      复杂任务
```

**优化建议**：
1. **任务分级**：简单任务用便宜模型，复杂任务用高级模型
2. **缓存利用**：ChatBrowserUse 的缓存 token 成本仅为正常的 1/10
3. **批量处理**：减少频繁的小任务调用
4. **结果验证**：用便宜模型做初筛，贵模型做最终确认

## 常见问题

### Q: 哪个模型最适合浏览器自动化？

**A**: **ChatBrowserUse** 是专门为浏览器自动化任务优化的模型，在准确性和速度之间取得了最佳平衡。平均完成任务的速度比其他模型快 3-5 倍。

### Q: 可以使用本地模型吗？

**A**: 可以。使用 **Ollama** 可以在本地运行模型，完全保护数据隐私。推荐使用 llama3.1:8b 或更大的模型。

### Q: 如何切换不同的模型？

**A**: 只需更改 LLM 初始化代码：

```python
# 使用 ChatBrowserUse
llm = ChatBrowserUse()

# 切换到 OpenAI
llm = ChatOpenAI(model="gpt-4o")

# 切换到 Anthropic
llm = ChatAnthropic(model="claude-sonnet-4-0")
```

### Q: 模型调用失败怎么办？

**A**: 检查以下几点：

1. **API Key 是否正确**：确保环境变量设置正确
2. **余额是否充足**：检查 API 提供商的账户余额
3. **网络连接**：确保能够访问 API 端点
4. **模型是否可用**：确认模型名称和版本正确

### Q: 为什么同一个任务在不同模型上表现不同？

**A**: 不同模型的训练方式和能力侧重不同：

- **推理能力**：o3 > Claude 3.5 > GPT-4o > Gemini
- **速度**：Gemini Flash > ChatBrowserUse > Groq > Claude
- **成本**：Ollama > Gemini > ChatBrowserUse > Claude/o3

## 前置条件

在开始之前，请确保你的系统满足以下要求：

- **Python 版本**：3.11 或更高版本
- **操作系统**：macOS、Windows、Linux
- **包管理器**：推荐使用 [uv](https://docs.astral.sh/uv/)，也支持 pip

</Note>

## 核心架构认知

在开始安装之前，先理解 Browser Use 的核心组件：

```
┌─────────────────────────────────────────────────────────────┐
│                    Browser Use 核心组件                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                    用户代码                          │   │
│   │   Agent(task="任务描述", llm=模型, browser=浏览器)   │   │
│   └─────────────────────────────────────────────────────┘   │
│                          ↓                                   │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                  Agent（代理）                        │   │
│   │   • 解析任务描述                                    │   │
│   │   • 规划执行步骤                                    │   │
│   │   • 调用 LLM 决策下一步                             │   │
│   │   • 通过 Browser 执行操作                           │   │
│   └─────────────────────────────────────────────────────┘   │
│                          ↓                                   │
│   ┌──────────────────┐    ┌──────────────────┐             │
│   │   LLM（大语言模型）  │    │  Browser（浏览器） │             │
│   │   • OpenAI        │    │  • Chromium      │             │
│   │   • Anthropic     │    │  • CDP 协议通信   │             │
│   │   • Google        │    │  • 执行实际操作   │             │
│   │   • ChatBrowserUse│    │  • 返回页面状态   │             │
│   └──────────────────┘    └──────────────────┘             │
│                                                              │
└─────────────────────────────────────────────────────────────┘

关键点：Agent 是协调者，LLM 负责思考，Browser 负责执行
```

## 第一步：安装 Browser Use

### 1.1 创建 Python 环境

```bash
# 使用 uv 创建虚拟环境（推荐）
uv venv --python 3.12
source .venv/bin/activate
# Windows 用户使用 `.venv\Scripts\activate`
```

**为什么使用 uv？**
- 比 pip 快 10-100 倍
- 自动管理依赖
- 支持 Python 3.11+

### 1.2 安装浏览器自动化库

```bash
# 安装 browser-use 包
uv pip install browser-use

# 安装 Chromium 浏览器
uvx browser-use install
```

<Warning>
**注意**：确保在安装完成后运行 `uvx browser-use install`，否则 Browser Use 无法控制浏览器。
</Warning>

### 验证安装

```bash
# 检查 Python 包是否安装成功
python -c "import browser_use; print('browser_use 版本:', browser_use.__version__)"

# 检查 Chromium 是否可用
uvx browser-use install --check
```

## 第三步：运行你的第一个代理

创建 `example.py` 文件并输入以下代码：

<CodeGroup>
  ```python Browser Use
  from browser_use import Agent, ChatBrowserUse
  from dotenv import load_dotenv
  import asyncio

  load_dotenv()

  async def main():
      # 初始化模型（推荐使用 ChatBrowserUse）
      llm = ChatBrowserUse()

      # 定义任务
      task = "访问 https://quotes.toscrape.com/，提取第一条名人名言和作者"

      # 创建代理
      agent = Agent(task=task, llm=llm)

      # 运行代理
      await agent.run()

  if __name__ == "__main__":
      asyncio.run(main())
  ```

## 第四步：理解执行结果

### 结果结构说明

代理运行完成后，你会看到以下输出：

```
# 执行历史：包含所有操作步骤的详细记录
# 截图路径：每个步骤的页面截图
# 提取内容：从页面中提取的结构化数据
```

```python
# 获取运行结果
history = await agent.run()

# 查看访问过的 URL
print(history.urls())

# 查看所有截图路径
print(history.screenshot_paths())

# 查看提取的内容
print(history.extracted_content())

# 查看最终结果
print(history.final_result())

# 查看执行步数
print(history.number_of_steps())
```

### 执行流程可视化

```
用户运行脚本
    ↓
Agent 初始化（加载 LLM、Browser）
    ↓
Agent.run() 开始执行
    ↓
循环步骤：
  1. 捕获当前页面状态（HTML + 截图）
  2. 发送给 LLM 分析
  3. LLM 返回下一个动作（如：click(3), input("text")）
  4. Browser 执行动作
  5. 验证结果，继续或调整策略
    ↓
任务完成或达到最大步数
    ↓
返回执行历史（history）
```

## 常见问题与排查

### 问题分类决策树

```
运行失败？
    ↓
┌─────────────────────────────────────────┐
│ 错误信息是什么？                          │
├─────────────────────────────────────────┤
│ "ModuleNotFoundError"                   │ → 包未安装
│ "API Key not found"                    │ → 环境变量问题
│ "No chromium found"                    │ → 浏览器未安装
│ "Connection timeout"                    │ → 网络问题
│ "Navigation failed"                    │ → 目标网站问题
└─────────────────────────────────────────┘
```

### Q: 代理运行失败怎么办？

**A**: 请按顺序检查：

1. **API Key 是否正确配置**
   ```bash
   # 检查环境变量
   echo $BROWSER_USE_API_KEY
   # 或在代码中验证
   from dotenv import load_dotenv
   import os
   load_dotenv()
   print("API Key:", os.getenv("BROWSER_USE_API_KEY"))
   ```

2. **Chromium 是否已安装**
   ```bash
   uvx browser-use install
   ```

3. **网络连接**
   - 确保能访问目标网站
   - 确保能访问 LLM API

4. **增加重试次数**
   ```python
   agent = Agent(
       task="任务",
       llm=llm,
       max_failures=5,  # 增加重试次数
   )
   ```

### Q: 如何提高任务成功率？

**A**: 建议尝试以下方法：

1. **使用更强大的模型**：如 `ChatBrowserUse` 或 `o3`
2. **增加步骤限制**：`max_steps` 参数可以设置最大步数
3. **添加初始操作**：`initial_actions` 可以预设一些操作
4. **使用视觉模式**：`use_vision=True` 让代理分析页面截图

### Q: 如何处理验证码？

**A**: 本地运行很难绕过验证码。建议使用：

1. **Browser Use Cloud**：提供隐身浏览器，可自动绕过大多数验证码
2. **代理配置**：使用高质量代理 IP
3. **手动干预**：在遇到验证码时暂停任务，人工完成验证

## 错误处理最佳实践

### 1. 设置合理的超时

```python
from browser_use import Agent, Browser, ChatBrowserUse

async def main():
    browser = Browser(
        step_timeout=120,  # 每个步骤超时 120 秒
    )

    agent = Agent(
        task="复杂任务",
        llm=ChatBrowserUse(),
        browser=browser,
        max_failures=3,    # 最多失败 3 次
    )

    history = await agent.run()
```

### 2. 捕获异常

```python
import asyncio
from browser_use import Agent, ChatBrowserUse

async def safe_run():
    try:
        llm = ChatBrowserUse()
        agent = Agent(task="你的任务", llm=llm)
        history = await agent.run()
        return history
    except Exception as e:
        print(f"执行失败: {e}")
        return None

history = asyncio.run(safe_run())
```

### 3. 验证结果

```python
history = await agent.run()

# 检查是否成功完成
if history.is_done():
    print("任务完成！")
    print(history.final_result())
else:
    print("任务未完成，可能需要更多步骤或调整任务描述")
    print(f"已执行步数: {history.number_of_steps()}")
```

### 进阶主题预览

#### 自定义浏览器配置

你可以通过 `Browser` 类自定义浏览器的行为：

```python
from browser_use import Agent, Browser, ChatBrowserUse
import asyncio

async def main():
    browser = Browser(
        headless=False,  # 显示浏览器窗口
        window_size={'width': 1280, 'height': 720},  # 窗口大小
        user_data_dir=None,  # 使用临时配置（None 表示无痕模式）
    )

    llm = ChatBrowserUse()
    agent = Agent(task="你的任务", llm=llm, browser=browser)
    await agent.run()

asyncio.run(main())
```

#### 添加自定义工具

扩展代理的功能，添加自定义工具：

```python
from browser_use import Tools, Agent, ChatBrowserUse

tools = Tools()

@tools.action(description='发送邮件')
async def send_email(to: str, subject: str, body: str) -> str:
    # 实现邮件发送逻辑
    return f"邮件已发送至 {to}"

agent = Agent(
    task="填写表单后发送确认邮件",
    llm=ChatBrowserUse(),
    tools=tools,
)
```

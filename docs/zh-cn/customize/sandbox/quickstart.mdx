## 核心概念

**沙箱（Sandbox）** 是运行 Browser Use 生产环境部署最简单的方式。我们处理代理、浏览器、持久化、认证、Cookie 和 LLM 的所有细节。

## 基础示例

只需用 `@sandbox()` 装饰器包装你的函数：

```python
from browser_use import Browser, sandbox, ChatBrowserUse
from browser_use.agent.service import Agent

@sandbox()
async def my_task(browser: Browser):
    agent = Agent(
        task="查找 Hacker News 排名第一的帖子",
        browser=browser,
        llm=ChatBrowserUse()
    )
    await agent.run()

# 异步调用
await my_task()
```

### 沙箱执行心智模型

```
用户代码
    ↓
@sandbox() 装饰器
    ↓
Browser Use Cloud（自动处理）
    ├── 浏览器实例分配
    ├── 认证同步
    ├── 代理配置
    └── 扩缩容管理
    ↓
执行结果返回
```

## 云端参数配置

```python
@sandbox(
    cloud_profile_id='your-profile-id',      # 使用保存的 Cookie/认证
    cloud_proxy_country_code='us',           # 绕过验证码、Cloudflare、地理限制
    cloud_timeout=60,                        # 最大会话时间（分钟）
)
async def task(browser: Browser, url: str):
    agent = Agent(
        task=f"访问 {url}",
        browser=browser,
        llm=ChatBrowserUse()
    )
    await agent.run()

await task(url="https://example.com")
```

## 参数说明

| 参数 | 说明 | 示例 | 适用场景 |
|-----|------|------|---------|
| `cloud_profile_id` | 使用云端配置保存的 Cookie 和认证 | `'profile-uuid'` | 需要登录态的任务 |
| `cloud_proxy_country_code` | 通过特定国家代理路由 | `'us'`、`'jp'` | 绕过地理限制 |
| `cloud_timeout` | 浏览器保持打开的最大时间（分钟） | `30`、`60` | 长时间运行任务 |

## 沙箱事件

你可以通过事件回调监控代理执行：

```python
from browser_use import sandbox

@sandbox()
async def monitored_task(browser: Browser):
    agent = Agent(
        task="你的任务",
        browser=browser,
        llm=ChatBrowserUse(),
    )

    # 代理开始执行
    agent.on("agent_start", lambda data: print(f"开始执行：{data}"))

    # 代理执行操作
    agent.on("action", lambda data: print(f"执行操作：{data}"))

    # 代理完成
    agent.on("agent_done", lambda data: print(f"完成：{data}"))

    await agent.run()

await monitored_task()
```

### 事件类型

| 事件 | 说明 | 数据内容 |
|-----|------|---------|
| `agent_start` | 代理开始执行 | 任务描述、Agent ID |
| `action` | 执行操作 | 操作类型、参数 |
| `agent_done` | 代理完成 | 执行结果、耗时 |
| `error` | 发生错误 | 错误信息 |

## 错误处理

```python
from browser_use import sandbox, BrowserUseError

@sandbox()
async def robust_task(browser: Browser):
    try:
        agent = Agent(
            task="你的任务",
            browser=browser,
            llm=ChatBrowserUse(),
            max_failures=3,  # 自动重试
        )
        history = await agent.run()
        return history
    except BrowserUseError as e:
        print(f"错误：{e}")
        return None

await robust_task()
```

### 错误处理最佳实践

## 沙箱 vs 本地部署对比

| 特性 | 沙箱部署 | 本地部署 |
|-----|---------|---------|
| **设置复杂度** | 一行代码 | 需要配置环境 |
| **浏览器管理** | 自动 | 手动 |
| **认证同步** | 自动 | 手动 |
| **隐身能力** | 高级（代理 + 指纹） | 基础 |
| **扩缩容** | 自动 | 手动 |
| **成本** | 按使用付费 | 免费（自备资源） |
| **数据隐私** | 上传云端 | 本地保留 |

## 常见问题

### Q: 沙箱如何保证数据安全？

**A**: Browser Use Cloud 采用企业级安全措施，包括：
- 数据加密传输
- 隔离的浏览器环境
- 自动清理会话数据

### Q: 如何选择沙箱还是本地部署？

**A**:

**选择沙箱的情况**：
- 需要快速上手
- 需要隐身功能
- 需要自动扩缩容
- 不想管理基础设施

**选择本地部署的情况**：
- 数据隐私要求高
- 需要完全控制环境
- 成本敏感
- 有运维能力

### Q: 沙箱支持自定义浏览器配置吗？

**A**: 沙箱会使用优化的默认配置。如需特殊配置，请使用本地部署。

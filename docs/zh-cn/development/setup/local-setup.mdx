## 环境搭建

### 1. 克隆仓库

```bash
git clone https://github.com/browser-use/browser-use
cd browser-use
```

### 2. 安装依赖

```bash
# 使用 uv sync 安装所有依赖（推荐）
uv sync --all-extras --dev

# 或使用 pip
pip install -U git+https://github.com/browser-use/browser-use.git@main
```

<Note icon="key" color="#FFC107" iconType="regular">
**推荐使用 uv**：`uv` 比 pip 快 10-100 倍，并且自动管理虚拟环境。
</Note>

### 3. 环境配置

设置你的环境变量：

```bash
# 复制示例环境文件
cp .env.example .env

# 设置日志级别（可选）
# BROWSER_USE_LOGGING_LEVEL=debug
```

## 辅助脚本

常用开发任务脚本：

| 脚本 | 功能 | 使用场景 |
|-----|------|---------|
| `./bin/setup.sh` | 完整设置脚本 | 首次搭建环境 |
| `./bin/lint.sh` | 运行所有检查 | 代码提交前 |
| `./bin/test.sh` | 运行测试套件 | 验证代码改动 |

```bash
# 完整设置脚本 - 安装 uv，创建虚拟环境，安装依赖
./bin/setup.sh

# 运行所有预提交钩子（格式化、 linting、类型检查）
./bin/lint.sh

# 运行 CI 中执行的核心测试套件
./bin/test.sh
```

## 代码规范

项目使用以下工具保持代码质量：

| 工具 | 功能 | 命令 |
|-----|------|------|
| **Black** | 代码格式化 | `black .` |
| **Ruff** | 代码 linting | `ruff check .` |
| **mypy** | 类型检查 | `mypy .` |

运行所有检查：

```bash
./bin/lint.sh
```

### 类型注解

所有公开 API 必须包含类型注解：

```python
from typing import List, Dict

def process_items(items: List[Dict[str, str]]) -> List[str]:
    """处理项目列表"""
    return [item["name"] for item in items]
```

### 文档字符串

使用 Google 风格的文档字符串：

```python
def function_name(param1: str, param2: int = 10) -> bool:
    """简要描述函数功能。

    Args:
        param1: 参数说明
        param2: 参数说明，默认值为 10

    Returns:
        返回值说明

    Raises:
        ValueError: 异常条件说明
    """
    pass
```

## 测试

### 编写测试

测试文件应位于 `tests/` 目录下：

```python
def test_example():
    """测试示例"""
    assert True
```

### 运行测试

```bash
# 运行所有测试
./bin/test.sh

# 运行特定测试
uv pytest tests/test_example.py
```

## 常见问题

### Q: uv sync 失败怎么办？

**A**:

1. **检查 Python 版本**：`python --version`（需要 3.11+）
2. **清除缓存**：`uv cache clean`
3. **重新安装**：`rm -rf .venv && uv sync`

### Q: lint.sh 检查不通过怎么办？

**A**:

1. **格式化代码**：`black .`
2. **修复 lint 错误**：`ruff check . --fix`
3. **类型检查**：`mypy .`（修复类型注解）

### Q: 测试失败怎么办？

**A**:

1. **查看错误信息**：运行 `uv pytest tests/ -v`
2. **检查是否破坏现有功能**：确保改动没有影响已有测试
3. **添加新测试**：为新功能添加对应测试

### Q: 如何添加新依赖？

**A**:

```bash
# 添加依赖到 pyproject.toml
uv add package-name

# 添加开发依赖
uv add --dev package-name
```

### Q: .env 文件应该包含什么？

**A**:

```bash
# API Keys（根据需要）
BROWSER_USE_API_KEY=
OPENAI_API_KEY=

# 日志级别（可选）
# BROWSER_USE_LOGGING_LEVEL=debug
```

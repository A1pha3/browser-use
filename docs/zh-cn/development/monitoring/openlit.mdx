## 核心概念

Browser Use 与 [OpenLIT](https://github.com/openlit/openlit) 原生集成 - 这是一个开源的 OpenTelemetry 原生平台，为你的 browser-use 代理执行的每个任务提供完整、详细的追踪。

安装 OpenLIT 和 Browser Use：

```bash
uv pip install openlit browser-use
```

## 使用

OpenLIT 提供**零代码更改**的自动、全面的检测，只需初始化即可：

```python {5-6}
from browser_use import Agent, Browser, ChatOpenAI
import asyncio
import openlit

# 初始化 OpenLIT - 就这么简单！
openlit.init()

async def main():
    browser = Browser()

    llm = ChatOpenAI(
        model="gpt-4o",
    )

    agent = Agent(
        task="找到 Hacker News 上的热门帖子",
        llm=llm,
        browser=browser,
    )

    history = await agent.run()
    return history

if __name__ == "__main__":
    history = asyncio.run(main())
```

<Note icon="key" color="#FFC107" iconType="regular">
**最佳实践**：在项目入口处初始化 OpenLIT，确保所有追踪被捕获。
</Note>

## 配置

### 自定义 OpenTelemetry 端点配置

```python
import openlit

# 配置自定义 OTLP 端点
openlit.init(
    otlp_endpoint="http://localhost:4318",
    application_name="my-browser-automation",
    environment="production"
)
```

### 环境变量

你也可以通过环境变量配置 OpenLIT：

```bash
export OTEL_EXPORTER_OTLP_ENDPOINT="http://localhost:4318"
export OTEL_SERVICE_NAME="browser-automation"
export OTEL_ENVIRONMENT="production"
```

### 自托管 OpenLIT

如果你希望将数据保存在本地：

```bash
# 使用 Docker
docker run -d \
  -p 4318:4318 \
  -p 3000:3000 \
  openlit/openlit:latest

# 在 http://localhost:3000 访问仪表板
```

## 与现有工具集成

OpenLIT 在底层使用 OpenTelemetry，因此它可以与以下工具无缝集成：

| 工具 | 用途 |
|-----|------|
| **Jaeger** | 分布式追踪可视化 |
| **Prometheus** | 指标收集和告警 |
| **Grafana** | 自定义仪表板和分析 |
| **Datadog** | APM 和日志管理 |
| **New Relic** | 全栈可观测性 |
| **Elastic APM** | 应用程序性能监控 |

只需配置 OpenLIT 导出到你现有的 OTLP 兼容端点即可。

## 常见问题

### Q: OpenLIT 和遥测数据有什么区别？

**A**:

| 特性 | 遥测数据 | OpenLIT |
|-----|---------|---------|
| 目标 | 库的使用统计 | 个人项目可观测性 |
| 数据 | 匿名聚合 | 详细追踪 |
| 配置 | 环境变量 | 代码初始化 |
| 可视化 | PostHog | 专用仪表板 |

### Q: 零代码更改是什么意思？

**A**: 只需调用 `openlit.init()`，无需修改 Agent 代码即可自动追踪所有操作。

### Q: OpenLIT 会影响性能吗？

**A**: OpenLIT 使用异步追踪，对性能影响极小。生产环境建议监控开销。

### Q: 如何导出到其他监控系统？

**A**: 配置 OpenLIT 的 OTLP 端点，导出到任何 OpenTelemetry 兼容的后端。

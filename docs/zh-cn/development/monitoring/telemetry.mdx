## 核心概念

Browser Use 在 MIT 许可证下免费使用。为了帮助我们持续改进该库，我们使用 [PostHog](https://posthog.com) 收集匿名使用数据。

```
┌─────────────────────────────────────────────────────────────┐
│                    遥测数据架构                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   Browser Use 库                                              │
│        ↓                                                     │
│   收集匿名数据                                               │
│   ├── 使用统计                                               │
│   ├── 性能指标                                               │
│   └── 错误报告                                               │
│        ↓                                                     │
│   PostHog（匿名聚合）                                         │
│        ↓                                                     │
│   用于改进库                                                  │
│   ├── 了解使用方式                                           │
│   ├── 修复错误                                               │
│   └── 优先功能                                               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

<Note>
即使启用，遥测数据也不会影响库的性能。代码可在 [遥测服务](https://github.com/browser-use/browser-use/tree/main/browser_use/telemetry) 中查看。
</Note>

## 收集的数据类型

我们收集的数据包括：

| 数据类型 | 内容 | 用途 |
|---------|------|------|
| **使用统计** | 功能使用频率、最常用的参数配置 | 了解功能使用情况 |
| **性能指标** | 执行时间、内存使用、错误率 | 性能优化 |
| **错误报告** | 异常类型、堆栈跟踪、发生频率 | 错误修复 |

### 不收集的数据

| 数据类型 | 说明 |
|---------|------|
| ❌ 个人身份信息 | 不收集任何可识别个人的信息 |
| ❌ API Key | 不收集认证令牌 |
| ❌ 任务描述 | 不收集具体任务内容 |
| ❌ 页面内容 | 不收集屏幕截图或页面内容 |

## 退出方式

你可以通过设置环境变量禁用遥测数据收集：

```bash .env
ANONYMIZED_TELEMETRY=false
```

或者在你的 Python 代码中：

```python
import os
os.environ["ANONYMIZED_TELEMETRY"] = "false"
```

## 数据隐私

### 匿名化处理

```
┌─────────────────────────────────────────────────────────────┐
│                    匿名化流程                                │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   原始数据                                                   │
│   ├── API 调用次数                                           │
│   ├── 错误类型                                               │
│   └── 执行时间                                               │
│        ↓                                                     │
│   匿名化处理                                                 │
│   ├── 移除个人标识符                                         │
│   ├── 聚合统计信息                                           │
│   └── 加密传输                                               │
│        ↓                                                     │
│   安全存储                                                   │
│   └── PostHog 服务器                                         │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 数据安全

| 措施 | 说明 |
|-----|------|
| 加密传输 | 使用 HTTPS 加密传输数据 |
| 匿名存储 | 不存储个人身份信息 |
| 合规存储 | 符合安全标准的服务器 |

## 常见问题

### Q: 遥测会影响性能吗？

**A**: 不会。遥测数据收集在后台异步进行，对库的性能影响为零。

### Q: 如何确认遥测已禁用？

**A**: 设置 `ANONYMIZED_TELEMETRY=false` 环境变量后，遥测数据将不再发送。

### Q: 可以查看收集的数据吗？

**A**: 不可以。所有数据都是匿名聚合的，无法追溯到个人用户。

### Q: 为什么需要遥测数据？

**A**: 遥测数据帮助我们：
- 了解功能使用情况
- 优先开发新功能
- 快速修复错误
- 优化性能
